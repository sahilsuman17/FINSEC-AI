# 🧠 Fraud Detection

FINSEC AI analyzes transaction amounts and compares them with the user's typical spending pattern.

The system generates a **risk score** and classifies transactions into different risk levels.

### Risk Levels

🟢 **Normal**

The transaction is within the normal spending range.

🟡 **Suspicious**

The transaction is significantly different from the user's usual spending pattern.

🔴 **High Risk**

The transaction amount is extremely unusual compared with the typical transaction pattern.

---

## 🤖 Machine Learning

FINSEC AI uses the **Isolation Forest** algorithm from Scikit-learn to identify unusual transaction patterns when sufficient transaction data is available.

The system combines:

- Transaction amount analysis
- Spending pattern comparison
- Anomaly detection
- Risk scoring

to provide an indication of potentially unusual transactions.

> ⚠️ **Note:** The risk score generated by FINSEC AI is a prototype anomaly/risk score. It should not be interpreted as a real-world probability of fraud.
